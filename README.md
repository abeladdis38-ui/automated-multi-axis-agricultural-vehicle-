# Design, Simulation and Prototyping of an Automated Multi-Task Agricultural Vehicle(AMAV)

# Bachelor's Thesis — Electromechanical Engineering

# Addis Ababa Science and Technology University (AASTU), June 2026

Overview:

This project presents the design and development of an automated multi-task
agricultural vehicle for soil digging, seed sowing, and tilling, aimed at improving efficiency and precision in small-scale and urban farming.

Highlights:

Integrated soil digging, seed sowing, and soil-covering mechanisms into a single compact robotic platform 
Mechanical design and structural analysis performed in SolidWorks
Dynamic modelling using the Euler–Lagrange method, represented in state-space form
PID controllers designed and tuned for locomotion, digging, and seed-dispensing subsystems
Functional prototype built and tested with embedded sensors, actuators,
motor drivers, and control systems

Keywords:

Automated Agriculture, Mobile Robot, Soil Digging Mechanism, Seed Sowing,
PID Control, Electromechanical System

Authors:
